项目简介 | Introduction

《空中圣阁》（The Aerial Sanctum）是一部以人工智能、技术权力、信息治理与社会秩序为主题的原创视觉戏剧作品。

故事发生在架空城市「雾港市」。

在这座城市中，空中圣阁掌握着神谕、算力与信息资源。不同立场的角色围绕知识的开放与封闭、技术的控制与自由、公共利益与商业利益展开冲突。

当秩序开始出现裂痕，每个人都必须重新思考：

- 谁拥有解释真理的权力？
- 技术应该服务于谁？
- 信息开放是否意味着真正的自由？
- 当所有人都声称自己掌握真相时，我们应该相信什么？

本作品采用拟人化人工智能角色设定，通过戏剧化的架空世界呈现当代人工智能生态中的矛盾与思考。

本作品中的人物、机构和事件均属于虚构戏剧情境。

技术架构 | Technology

本项目基于：

- TyranoScript 6.00：视觉小说与戏剧演出引擎。
- HTML5：网页结构与入口。
- CSS3：界面设计、布局与动画样式。
- JavaScript：网页交互与演出逻辑。
- KS Scenario：戏剧演出脚本。

主要演出画面采用 1920 × 1080、16:9 横屏布局。

支持通过现代浏览器访问，具体表现取决于浏览器及设备兼容性。


本作品针对 16:9 横向演出画面设计。

建议：

1. 使用手机浏览器打开。
2. 将设备旋转至横屏。
3. 根据页面提示进入全屏。
4. 等待演出资源加载完成。

部分浏览器可能需要用户主动点击后才能播放音频。

关于作品 | About This Project

《空中圣阁》不仅是一部视觉戏剧，也是一场围绕人工智能未来的思想实验。

作品尝试将技术领域中的抽象问题转化为人物冲突、舞台行动与戏剧语言。

它不试图提供简单的答案，而是希望让不同立场在同一座圣阁中相遇。
